PERSONA & TUGAS Static
ANDA ADALAH: Senior Conversion Copywriter + UI/UX minded marketer... TUGAS ANDA: Menulis Copywriting Landing Page (Sales Page)...
ATURAN PENULISAN (12 Rules) 12 Variables
1. LAYOUT: da (platform-based) 2. TEMA VISUAL: dn (color + CSS override) 3. HERO TYPE: hn (hero_type) + Hi (layout instruction) 4. STICKY CTA: Ns (sticky_mobile ? YA : TIDAK) 5. SCARCITY: Bi (scarcity_type) 6. Skimming-friendly (static) 7. Anti Overclaim (static) 8. Awareness: u.awareness 9. Tone: u.tone 10. Gambar & Icon (static placeholder URL) 11. Styling Tombol (static CSS rules) 12. Target CTA: Hn (scroll/URL/WA)
PROFIL PRODUK & MARKET 6 Variables
- Nama Produk: u.product_name - Kategori: J (category_base || custom) - Deskripsi: u.description - Target Market: Ee (target_base || custom) - Tujuan Utama: u.goal - Framework: u.framework
PSIKOLOGI AUDIENS 2 Variables (reused 2x)
- Pain Points: ha (pain_points || fallback) --> juga masuk ke HERO SECTION - Objection: me (objections || fallback) --> juga masuk ke OBJECTION BLOCK
PENAWARAN (OFFER STACK) 4 Variables
- Harga Normal: u.price_normal - Harga Promo: u.price_promo || "Tidak ada promo" - Bonus: Pr (has_bonus ? detail : "Tidak ada") - CTA: "Ue (cta_base || custom)"
STRUKTUR HALAMAN 7 Variables
PLATFORM: At (platform) 1. HERO: Hook relevan dengan ha (pain_points) 2. BODY: Alur framework u.framework 3. OBJECTION BLOCK: Jawab "me (objections)" 4. ADDITIONAL SECTIONS: ra (joined checkboxes) 5. TRUST ELEMENTS (static) 6. CONVERSION BLOCK: urgensi Bi (scarcity) 7. HIDDEN CTA (static) vt (extra block jika sections > 0)
OUTPUT INSTRUCTION 2 Variables
HTML utuh (single file) + Tailwind CSS Visual: u.design_style Warna: pt (brand_color || custom hex)
Platform -> Layout da
platform === "Lynk.id"
"Desain WAJIB menggunakan SATU KOLOM TUNGGAL (Single Column). Jangan gunakan grid multi-kolom."
else (semua platform lain)
"Desain bebas multi-kolom" (Scalev, Berdu, WordPress, Shopify, dll.)
Hero Type -> Layout Instruction Hi
hero === "VSL"
"HERO SECTION: Gunakan layout VSL. Video embed (placeholder YT/Vimeo) harus menjadi fokus utama, dengan Headline besar di atasnya dan tombol CTA di bawahnya. JANGAN gunakan gambar samping."
hero === "Typographic"
"HERO SECTION: Gunakan layout Typographic Only (Teks Besar)"
else (Standard)
"HERO SECTION: Gunakan layout Hero standar (Gambar/Ilustrasi + Copy)."
Sticky Mobile Button Ns
sticky_mobile === true
"WAJIB membuat tombol CTA Melayang (Sticky Bottom) yang hanya muncul di layar mobile agar mudah diakses saat scroll."
sticky_mobile === false
"Tidak perlu sticky button."
CTA Target Type -> href Instruction Hn
cta_target === "scroll"
"Arahkan href semua tombol CTA agar SCROLL ke form/section terbawah halaman (gunakan anchor tag)."
cta_target === "url"
"Arahkan href SEMUA tombol CTA secara langsung ke URL: [user input]"
cta_target === "wa"
"Arahkan href ke link WhatsApp: https://wa.me/[nomor]"
Custom vs Dropdown (3 fields) J, Ee, Ue
dropdown === "custom"
Pakai teks yang diketik user di input manual (category_custom, target_custom, cta_custom)
else
Pakai value dari dropdown langsung (category_base, target_base, cta_base)
Bonus Details Pr
has_bonus === true && detail
Pakai teks bonus yang diisi user
has_bonus === true && !detail
"Tidak ada detail."
has_bonus === false
"Tidak ada bonus tambahan."
Additional Sections (checkboxes) ra + vt
sections.length > 0
ra = checked items joined by ", " (e.g. "Social Proof, FAQ, Guarantee")
vt = inject extra block: "PENTING: HIGHLIGHT SECTION TAMBAHAN - AI WAJIB membuat section: [list]"
sections.length === 0
ra = "Standar"
vt = "" (kosong, tidak ada tambahan)
Fallback Values ha, me
pain_points === ""
ha = "Tidak dispesifikan, harap riset mandiri."
objections === ""
me = "Umum (Harga/Kualitas)."
ada isi
Pakai teks yang diisi user langsung
